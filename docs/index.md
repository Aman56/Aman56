## Featured Project

<div class="project-card">
  <h3>Audience Personalization via Synthetic Respondents</h3>
  <p><strong>Organization:</strong> Resonate Networks | <strong>Status:</strong> Production</p>
  <p><strong>Problem:</strong> Traditional audience segmentation relies on limited demographic data and fails to capture nuanced behavioral preferences. Existing models achieve modest accuracy on holdout user populations.</p>
  <p><strong>Solution:</strong> Built an end-to-end personalization pipeline grounded in survey science: adaptive survey framework, synthetic respondent generator (multi-task DNN), and inference pipeline serving 3T example rows on AWS.</p>
  <p><strong>Outcomes:</strong> +5% lift over baseline · 3T-row inference with <200ms p99 latency · 12% improvement in campaign targeting precision · Production deployed and sustaining performance.</p>
  <p><strong>Tech Stack:</strong> <span class="tech-tag">PyTorch</span> <span class="tech-tag">Python</span> <span class="tech-tag">AWS</span> <span class="tech-tag">PostgreSQL</span> <span class="tech-tag">Redis</span> <span class="tech-tag">FastAPI</span></p>
  <p><a href="/projects/">View all projects →</a></p>
</div>
